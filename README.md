🚀 Superstore Sales Dashboard - Interactive Visualization

🎯 Task 8: Simple Sales Dashboard Design

📁 Dataset Used  
Dataset: Superstore_Sales.csv  
Source: Sample dataset provided (Superstore Sales)  
Tool: Power BI  
Environment: Power BI Desktop

📌 Objective  
The goal of this project was to create an interactive and visually informative dashboard to analyze sales performance by product category, region, and time (month-year). This dashboard provides business users with a quick overview of sales and profit metrics, enabling them to identify trends, top-performing areas, and regional variations.

🛠 Methods Used  
- Power BI for interactive dashboard creation  
- Data Cleaning (optional step): Python + Pandas  
- Data transformation: Converted Order Date to “Month-Year”  
- Visualizations added:
  - Line Chart: Sales over Months  
  - Bar Chart: Sales by Region  
  - Donut Chart: Sales by Category  
- Slicers for Region to allow user-driven filtering  
- Color coding to highlight top-performing areas  

📊 Key Visualizations  
1. **Line Chart**: Monthly trend of sales across the dataset period  
2. **Bar Chart**: Comparison of sales volume by different regions  
3. **Donut Chart**: Breakdown of sales contribution by product category  

💡 Insights  
- The **West region** recorded the highest sales in Q3.  
- **Technology** category had the largest share in total sales.  
- **South region** consistently showed lower sales compared to others.  
- Sales increased significantly during **holiday months**, especially November and December.
